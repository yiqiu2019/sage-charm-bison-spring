## 规格约定

- **单位米，Y 朝上，底部贴地**：模型最低点 Y = 0，水平中心在原点。直接放在地面高度即可，不需要再偏移。
- **正面朝 +Z**：粮仓的封板仓口在 +Z 一侧。三个模型都基本是圆的，摆放时随机绕 Y 轴旋转就行，但同一个堆场里仓口最好大致朝向场院中间或道路。
- **缩放**：模型已经是实际尺寸，`scale = 1`。可以在 0.9–1.1 之间随机，粮仓之间、禾堆之间看起来就不会一模一样。不要超出这个范围，否则和船、人的比例对不上。
- **压缩**：EXT_meshopt_compression + 顶点量化，加载器要配 `MeshoptDecoder`（规格第九节）。贴图是 WebP：lod0 1024、lod1 512、lod2 256。
- **材质**：已去掉金属度（metallicFactor 0）和 KHR_materials_specular。加载后按规格设 `specularIntensity 0.5`。**单面渲染**（1.1 版改动：双面会在阴影里自遮挡发黑）。粮仓 A 的泥墙原本偏橙黄，已降饱和 28%。

## 显示距离（以相机为准，同规格第七节树木）

| 精度 | 距离 |
|---|---|
| lod0 | 60 米以内 |
| lod1 | 60–200 米 |
| lod2 | 200–600 米 |
| 隐藏 | 600 米以外 |

切换处渐变，不能在船附近突然出现或消失。手机：距离乘 0.7。

重复摆放时用 InstancedMesh，按精度分组，每种模型每档精度一个 InstancedMesh。

## 已知局限

- 混元生成的模型 UV 接缝多，lod2 的 600 面版本近看贴图有拉伸，200 米外看不出来。
- 禾堆侧面的捆扎层比较规整，像一圈圈箍。多个禾堆随机旋转、缩放后就不明显了。
