# 赵王城 3D 网页 · 项目规格（PROJECT_SPEC.md，第 2 版）

## 一、这是什么
Three.js 网页游戏：玩家划一条小船，沿战国赵国宫城"赵王城"（品字形三城）外的护城河**顺时针**绕一圈。不能进城，没有任务和剧情。目标是**战国盛期复原**：华丽，但只用战国自己的做法（夯土高台、白灰墙、丹漆柱、青铜构件、帷幔、平直屋檐）。季节：华北晚秋。

## 二、工作规则
1. 本文件里的数字是定稿，不要自行"优化"。冲突或无法实现时按最保守的方式处理，并在交付说明里列出。
2. 一次只做一个任务。每个任务交付：截图 + 改了哪些文件 + 偏离清单。
3. **节省 token**：不要通读整个项目。用搜索（grep）定位相关代码，只打开要改的文件和段落；规格只查本文件对应小节。
4. 着色器安全：`normalize()` 输入可能为零时用 `v / max(length(v), 1e-5)`；除法分母加 `max(x, 1e-5)`；`pow`/`sqrt` 输入先 `max(x, 0.0)`；高光、自发光钳制上限；泛光前过滤 NaN/Infinity。**任何改动都不能产生黑块。**
5. 交付两个版本：开发版（`public/` 下按相对路径加载资源）和单文件版 `zhaowangcheng_standalone.html`（资源 base64 内嵌，16MB 以内）。
6. 能自己跑就自己截图验收。

## 三、技术约定
- Three.js 固定 **0.170.0**。
- **规格坐标**：单位"游戏米"，+X 东、+Z 北、Y 上；尺寸写作 X×Y×Z。
- Three.js 是右手系，+Z 朝南。代码里用转换函数 **规格 (x, z) → Three.js (x, −z)**，本文件所有坐标都要经过它。验收：开场向西看，城在画面右侧。
- 方位角从正北顺时针量。
- 灯光强度：本文件的规格值在代码里**乘以 π**（r170 去掉了旧版 π 预乘）。
- 画质：桌面"高"、手机"低"，自动判断；`?q=high` / `?q=low` 强制。
- 调试开关：`?fps=1` 帧率；`?post=0` 关后期；`?veg=0` 隐藏植被；`?water=0` 隐藏水面。
- 性能：桌面约 150–200 万三角面、绘制调用 200 以内、60 帧；手机横屏 30–50 万面、100 以内、不低于 30 帧。
- **重复物体一律 InstancedMesh，按约 60×60 分区块，正确计算每块的包围球**；按相机距离切换精度，切换处渐变过渡，**不能在船附近突然出现、远处消失**。

- 双阙：西阙 X 103–119、东阙 X 137–153，Z −11 到 0；台顶 Y 14.8；台顶放 pavilion 模型

- 龙台：X 111–153、Z 55–101；三层 Y 0.8–10.8 / 10.8–18.8 / 18.8–24.8，上两层往北错开；南面三段大台阶宽 6；各层回廊红柱；顶层放 hall2 模型，中心 (132, 85)

## 六、颜色、材质、光
- 白灰 #E8DFCC；丹漆 #9E2B1F；黑漆 #1C1612；暗褐木 #4A3226；码头木 #5A4330；青铜 #8C6A3A（metalness 0.6）；青灰瓦 #5E6468；帷幔 #EFE6D2
- **夯土**：偏灰黄土色，基础约 #A8987A，**不要橙色**；层理每层 0.4–0.6 随机、对比弱；大尺度噪声、墙脚湿痕、雨痕、修补色块，打破重复
- 水：基础色 #2F2A24，暗部亮度不低于约 0.06；反射 0.35–0.5，菲涅尔控制；近岸 3–6 渐变到浅水色约 #4A3F2E；岸边浅沫窄而淡（宽 0.3–0.8、不透明度 ≤0.3），**不能有刺眼的白色反光带**
- **黄昏**：太阳方位 248°、高度角 10°，贴近西面山脊，日轮小而清晰、外圈柔和光晕。暖色只在太阳一侧和受光面；天空从地平线暖橙往上过渡到灰紫、灰蓝；阴影和远景偏冷；整体饱和度克制，**不能整片橙红**
- 雾：黄昏线性雾 near 80、far 600（夜火、晨雾按比例）；雾色与地平线附近天空一致；城外地面铺到离城中心约 900，边缘用雾淡出
- 三个时段：黄昏 / 夜火 / 晨雾，右上角三个圆点切换，2 秒平滑过渡

## 七、岸与植被（晚秋）
- **不要柳树**（已决定全部删除）
- **内岸**（墙脚到水边）：矮草（grass，缩到 0.25–0.5）稀疏整洁，墙脚一条湿痕，水边 1–2 宽湿泥带，零星碎石；不种树、芦苇、灌木
- **外岸**：水边碎石和湿泥带；芦苇用 reed 贴图集成团摆放，北面最密成芦苇荡，南面码头和桥两侧 30 内留空；野草和灌木用 grass_shrub 贴图集成片分布
- **树木**：用 t0（槐）、t1（榆）、t2（桑树丛/杂树丛）模型。外岸 2–3 棵成簇、间隔 40–120、离水 8–30；宅院院中一棵 t0；村落 2–4 棵加几丛 t2；田边零星；村旁两片桑林（t2 排成行）；军营、校场、内岸不种
- 显示距离（以相机为准，切换处渐变）：
  - 芦苇：200 内完整，200–350 减半单面片，350–500 剩 1/4，500 外隐藏
  - 野草：120 内完整，120–250 减半，250 外隐藏；灌木：200 内完整，200–400 减半，400 外隐藏
  - 树：lod0 60 内，lod1 60–200，lod2 200–600，600 外隐藏
  - 手机：距离乘 0.7，数量减半
- 所有植被有风摆，同一风向；防 NaN
