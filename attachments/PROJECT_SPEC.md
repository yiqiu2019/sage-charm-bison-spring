# 赵王城 3D 网页 · 项目规格（PROJECT_SPEC.md）

## 一、这是什么
Three.js 网页游戏：玩家划一条小船，沿战国赵国宫城"赵王城"（品字形三城）外的护城河**顺时针**绕一圈。不能进城，没有任务和剧情。目标是**战国盛期复原**：华丽，但只用战国自己的做法（夯土高台、白灰墙、丹漆柱、青铜构件、帷幔、平直屋檐）。

## 二、工作规则
1. 本文件里的数字是定稿，不要自行"优化"。冲突或无法实现时按最保守的方式处理，并在交付说明里列出。
2. 一次只做一个任务。每个任务交付：截图 + 改了哪些文件 + 偏离清单。
3. **节省 token**：不要通读整个项目。用搜索（grep）定位相关代码，只打开要改的文件和段落；规格只查本文件对应小节。
4. 着色器安全：`normalize()` 输入可能为零时用 `v / max(length(v), 1e-5)`；除法分母加 `max(x, 1e-5)`；`pow`/`sqrt` 输入先 `max(x, 0.0)`；高光、自发光钳制上限；泛光前过滤 NaN/Infinity。**任何改动都不能产生黑块。**
5. 交付两个版本：开发版（`public/` 下按相对路径加载资源）和单文件版 `zhaowangcheng_standalone.html`（资源 base64 内嵌，16MB 以内）。
6. 能自己跑就自己截图验收。

## 三、技术约定
- Three.js 固定 **0.170.0**。
- **规格坐标**：单位"游戏米"，+X 东、+Z 北、Y 上；尺寸写作 X×Y×Z。
- Three.js 是右手系，+Z 朝南。代码里用转换函数 **规格 (x, z) → Three.js (x, −z)**，本文件所有坐标都要经过它。验收：开场向西看，城在画面右侧。
- 太阳方位角从正北顺时针量。
- 灯光强度：本文件的规格值在代码里**乘以 π**（r170 去掉了旧版 π 预乘）。
- 画质：桌面"高"、手机"低"，自动判断；`?q=high` / `?q=low` 强制。
- 调试开关：`?fps=1` 帧率；`?post=0` 关后期；`?veg=0` 隐藏植被；`?water=0` 隐藏水面。
- 性能：桌面约 150–200 万三角面、绘制调用 200 以内、60 帧；手机横屏 30–50 万面、100 以内、不低于 30 帧。重复物体一律 InstancedMesh，按距离切 LOD。

## 六、颜色、材质、光
- 白灰 #E8DFCC；丹漆 #9E2B1F；黑漆 #1C1612；暗褐木 #4A3226；码头木 #5A4330；青铜 #8C6A3A（metalness 0.6）；青灰瓦 #5E6468；帷幔 #EFE6D2
- **夯土**：偏灰黄土色，基础约 #A8987A，**不要橙色**；层理每层 0.4–0.6 随机、对比弱；加大尺度噪声、墙脚湿痕、雨痕、修补色块，打破重复
- 水：基础色 #2F2A24，暗部亮度不低于约 0.06；反射 0.35–0.5，菲涅尔控制；近岸 3–6 渐变到浅水色约 #4A3F2E
- **黄昏调色**：太阳方位 248°、高度角 10°。暖色只在太阳一侧和受光面；天空从地平线暖橙往上过渡到灰紫、灰蓝；阴影和远景偏冷；整体饱和度克制，**不能整片橙红**
- 三个时段：黄昏 / 夜火 / 晨雾，右上角三个圆点切换，2 秒平滑过渡

## 七、岸与植被
- **内岸**（墙脚到水边）：矮草（0.2–0.5）成片但不密，墙脚一条湿痕，水边 1–2 宽湿泥带，零星碎石；不种树和芦苇
- **外岸**：水边碎石和湿泥带；芦苇按丛（每丛 10–25 株），北面最密成芦苇荡，南面码头和桥附近留空；草丛、灌木一片一片分布；垂柳用柳条贴图集
- 季节：晚秋
- 植被全部实例化，有风摆，防 NaN；远处简化，手机减半
