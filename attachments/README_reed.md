# 芦苇丛贴图集

- reed_clumps_2048.webp（桌面）/ reed_clumps_1024.webp（手机），RGBA，背景透明；另附同名 PNG 备用
- 一张图里 4 丛芦苇，各自的 UV 范围见 reed_clumps_uv.json；每丛的根部在矩形底边
- 透明区域颜色已外扩，开 mipmap 不会出白边

## 用法
- 每丛用 2–3 张交叉的竖直面片（绕竖轴各转 60°–90°），根部埋进地面 0.1
- 尺寸：高 1.8–3.0 随机，宽度按 width_over_height
- 每个实例随机：4 丛里随机选一丛、绕竖轴随机旋转、左右镜像（u 翻转）50% 概率、整体缩放 ±20%、颜色偏移 ±10%（instanceColor）
- 成片摆放：几丛到十几丛挤成一团，团与团之间疏密不均；贴着外岸水边 0–5，北面最密成芦苇荡，南面码头和桥附近留空
- 风：顶点着色器里按面片高度加摆动，根部不动，顶部摆幅最大，芦花部分（面片上 40%）摆得更明显；每丛相位随机
- 材质：alphaTest 0.4，DoubleSide，不开半透明混合；桌面开 alphaToCoverage
- 远处（120 以外）每团只保留一半的丛，150 以外隐藏
- 着色器防 NaN
