# clouds · 云层贴图（第 1 版）

规格第十二节第 9 项"云层"。一张可以无缝平铺的高空云层贴图（从地面正上方仰视），投影到假想的水平云层上，覆盖整个天空。

| 文件 | 尺寸 | 用途 |
|---|---|---|
| `clouds_1024.webp` | 1024 × 1024，RGBA | 桌面"高" |
| `clouds_512.webp` | 512 × 512，RGBA | 手机"低"、单文件版 |
| `preview_sky.png` | — | 示意：船的高度向西（黄昏太阳方向）和向东北看。天空底色是测试用的，不是游戏里的颜色 |

**通道含义**（线性，不要设成 sRGB）：

- **R（= G = B）：云的亮度/厚度**，0–1。云越厚越亮。用来决定受光多少。
- **A：云的覆盖度**，0–1。已经调过，A > 0.5 的面积约 28%，平均 0.29，是"晴间多云"的感觉，不会把天空塞满。如果要更多或更少的云，在着色器里对 A 做 `smoothstep(k, 1.0, A)` 之类的调整，不要改贴图。

**处理**：GPT 原图四边接缝明显，已用错位融合修成可无缝平铺；原图覆盖度约 57%，太满，已降到约 28%。

## 做法：写在天空球的着色器里，不要用一块大平面

规格第八节要求天空球放在远景场景里，远景相机 far = 3000。云层要看到一万多米远才会自然地压向地平线，用一块真实的大平面会被 far 裁掉。所以在**天空球的片元着色器里**算：

1. 视线方向 `d`（单位向量，相机朝外）。只在 `d.y > 0.01` 时有云。
2. 视线和高度 `H = 1500` 的水平面求交：`dist = H / max(d.y, 0.01)`，交点水平坐标 `p = d.xz * dist`（相机水平位置可以忽略，或者加上，效果差不多）。
3. 采样：`c = texture(clouds, p / TILE)`，`TILE = 6000`（一张贴图对应 6 公里）。
4. **打破重复**：再采样一次 `texture(clouds, rot(p, 37°) / 9000 + 0.31)`，两次用 `max` 或按 0.6/0.4 混合。
5. **漂移**：两次采样分别加时间偏移，风从西北吹向东南（华北晚秋），速度很慢，约每秒 3 和 5 米（世界单位），两层速度不同就会有层次。
6. **随距离淡出**：`fade = 1 - smoothstep(6000, 16000, dist)`。远处的云融进地平线的天空色，地平线附近不能出现一条清楚的云边。
7. **染色**（参考，Grok 按实际天空调）：
   ```
   sd    = max(dot(d, sunDir), 0)                     // 朝太阳的程度
   shade = mix(云暗部色, 云亮部色, c.r*0.55 + pow(sd,3)*0.6)
   col   = mix(地平线天空色, shade, 0.35 + 0.65*fade)
   alpha = c.a * fade * 0.9
   天空最终 = mix(天空色, col, alpha)
   ```
   - 黄昏：亮部偏暖（约 #F2B894），暗部偏冷灰紫（约 #6B6178）。太阳一侧的云边最亮，背阳一侧偏冷。
   - 夜火：云很暗，比夜空略亮一点点，只看得出轮廓；火光不照到云。
   - 晨雾：云发灰白、低对比，大部分被雾遮住。
8. 防 NaN（规格第二节第 4 条）：`d.y` 用 `max(d.y, 0.01)`；`pow` 的输入先 `max(x, 0.0)`。

## 注意

- 开 mipmap 和各向异性过滤（anisotropy 8），否则地平线附近的云会闪。
- 云不能遮住太阳日轮的中心（规格第六节"日轮小而清晰"）：在太阳方向 3° 以内，把云的 alpha 压到 0.3 以下。
- 远景带（山影、平原远景带、大北城）画在云的前面。
