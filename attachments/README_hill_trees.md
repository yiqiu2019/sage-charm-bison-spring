# hill_trees · 远山树木公告板贴图集（试样第 1 版）

给规格第八节"西面田野之外 3D 低缓丘陵"（离城中心 600–850）铺树用。**只用于远景公告板**，不用于岸边、村落、田边的近景树（那些仍用 t0/t1/t2 模型，见规格第七节）。

## 怎么用

**几何**：每棵树一个竖直四边形，InstancedMesh，所有树共用一个材质，1–2 次绘制调用。

- 四边形高 = 树高 h（在建议范围内随机），宽 = h × `aspect`。
- UV 用 `hill_trees.json` 里每格的 `uv`（u0,u1,v0,v1）。已按 three.js 默认 `flipY = true` 换算好（v 从下往上）。
- **朝向**：圆柱公告板，只绕 Y 轴转向相机，不前后俯仰。每棵树随机水平翻转（uv 左右互换），增加变化。
- **落地**：四边形底边比地面低 0.3 米，免得在坡上悬空。在坡上取树根处的地面高度，不取包围盒最低点。

**材质**：

- 光照已经烘焙在贴图里（柔和顶光加左前方暖光）。不要再用 PBR 光照打一遍，否则背光面会发黑。用不受光的材质，乘一个按时段变化的颜色：黄昏偏暖、晨雾偏灰亮、夜火很暗偏冷，跟随场景其他远景。
- 要受雾影响（规格第六节线性雾）。远处的树应逐渐融进雾色，不能是一排排黑点。
- alphaTest 约 0.4；桌面"高"可开 alphaToCoverage，边缘更柔。
- 着色器防 NaN（规格第二节第 4 条）。

**缩放和显示距离**：

- 这些树离相机约 400–1200 米，在屏幕上大多是 5–40 像素高。始终显示，靠雾淡出，不需要远中近三档模型。
- 桌面用 2048 版，手机用 1024 版；手机数量减半（规格第七节）。
- 为了让坡面看起来"满"，同一视野里应有几千棵，相互重叠。示意图里约 2300 棵。

## 已知局限（下一版要补的）

1. **pine_a / pine_b 不是针叶树形状**。来源模型 tree_2 是阔叶树冠，只是染成了墨绿。远处能当作常绿树的深色块，但缺少侧柏的塔形轮廓。需要一个 EZ-Tree 针叶预设的模型来替换。
2. bare_a 枝条很细，在远处几乎看不见，只适合零星放在山脊上。
3. 只有一个角度，没有法线贴图。远景够用；如果以后要用到 200 米以内，需要另做多角度版本。

## 来源

由用户提供的 EZ-Tree 模型渲染：tree.glb、tree_1.glb（栎、黄栌、落叶树）、tree_2.glb（常绿树）、tree_4.glb（灌丛）。叶色在渲染时重新着色，和导出时的原色无关。正交相机从侧面拍摄，每格 512 像素。
