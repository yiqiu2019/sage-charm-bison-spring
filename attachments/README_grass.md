# 草丛与灌木贴图集

- grass_shrub_2048.webp（桌面）/ grass_shrub_1024.webp（手机），RGBA，背景透明；另附同名 PNG 备用
- 上排 3 丛野草（kind: grass），下排 3 丛灌木（kind: shrub）；各自 UV 范围见 grass_shrub_uv.json，根部在矩形底边
- 透明区域颜色已外扩，开 mipmap 不会出白边

## 野草 grass
- 每丛 2 张交叉的竖直面片，根部埋进地面 0.05
- 外岸和城外：高 0.5–1.2；内岸（墙脚到水边）：只用作矮草，高 0.25–0.5，密度低，保持整洁
- 成片摆放：用低频噪声控制疏密，一片一片，有空地；田埂、路边、建筑周围多一些

## 灌木 shrub
- 每丛 2–3 张交叉面片，高 0.8–1.6
- 稀疏点缀：外岸、田边、村落旁、宅院墙外，几丛成簇；内岸不放

## 共同规则
- 每个实例随机：在同类里随机选、绕竖轴旋转、50% 左右镜像、缩放 ±20%、颜色偏移 ±10%（instanceColor）
- 风：顶点着色器，根部不动、顶部摆动；野草摆幅大、灌木摆幅小；与芦苇、柳树同一风向
- 材质：alphaTest 0.4，DoubleSide，不开半透明混合；桌面开 alphaToCoverage
- 显示距离（以相机为准）：野草 120 以内完整，120–250 减半，250 以外隐藏；灌木 200 以内完整，200–400 减半，400 以外隐藏；边界前后 30 内渐变过渡，不能突然出现或消失
- 按约 60×60 分区块，每块一个 InstancedMesh，正确计算包围球
- 手机：距离乘 0.7，数量减半
- 着色器防 NaN
