# 旗面贴图

- flag_1024.png（448×1536，桌面）/ flag_512.png（224×768，手机），RGBA，背景和飘带之间的空隙是透明的
- 宽高比约 0.29：旗面宽 W 时总高约 3.4W
- 从顶部往下 0–0.755 是旗面，0.755–1.0 是三条飘带
- 旗子挂法：顶边固定在旗杆顶的横杆上，自然下垂；飘动时顶边不动，越往下摆幅越大，飘带部分（v 从顶部算 0.755 以下）摆幅再加大一倍
- 材质：alphaTest 0.4，side DoubleSide，不开半透明混合；透明区域颜色已外扩，不会有白边
- 尺寸建议：城墙旗宽 1.4（总高约 4.8）；将台大军旗宽 2.5（总高约 8.5）；桥头旗宽 1.2
